@@ what it does @@

Every difference found.
Every deploy accounted for.

Compare any two schemas — then act on what you find with a script you can read before you run.

compare

40+ object types, line by line

Tables, functions, types, policies, triggers, and more — side by side with line-level highlighting, a plain-English summary, and dependency chips linking related objects.

deploy

Deployment scripts, dependency-ordered

One click generates the SQL to bring two schemas in sync — in an order that actually runs, with destructive statements surfaced in red before anything else.

data pro

Rows, not just structure

Compare the data itself, see which rows differ, and generate the INSERT, UPDATE and DELETE statements to reconcile them. Export any table's differences to CSV.

automate pro

The pgc CLI and pipelines

Run the same comparisons from CI, fail a build when a schema drifts unexpectedly, and chain steps into repeatable pipelines. No interface required.

track pro

Schema history and drift

Keep every comparison you run. Watch your schema evolve in a swimlane view, and catch drift between environments before it reaches an incident channel.

agents pro

Built for AI-assisted workflows

The bundled MCP server lets coding agents run comparisons and read the results. Read-only mode and environment allow-lists control exactly what an agent can reach.

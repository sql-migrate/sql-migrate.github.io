        <h3>Our mission</h3>
        <p>PostgreSQL is battle hardened, reliable and free. In recent years it has become one of the most loved and wanted database technologies among developers. PostgresCompare provides PostgreSQL users the tools they need to take the pain out of managing and deploying different environments.</p>
      </div>

      <div class="cell prose">
        <h3>Meet Neil</h3>
        <p><a href="https://www.postgrescompare.com">PostgresCompare</a> is the work of founder Neil Anderson. An experienced software engineer, Neil spent a large chunk of his career working on database diffing tools targeting SQL Server, Oracle and MySQL at <a href="https://www.red-gate.com">Redgate Software</a>.</p>
        <p>Now he builds PostgresCompare full time: a schema comparison tool for PostgreSQL that finds every difference and writes SQL you can read before you run it.</p>
        <p>Contact Neil by <a href="mailto:neil@postgrescompare.com">email</a> and let him know how he can make PostgresCompare work for you.</p>
